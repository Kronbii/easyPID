# Security Policy

## Supported Versions

Security fixes are applied to the latest code in the default branch.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |
| older releases/commits | No |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Preferred reporting path:

1. Use GitHub's private vulnerability reporting (Security tab -> Advisories ->
   Report a vulnerability) if enabled for this repository.

Fallback path:

1. Contact the maintainer directly via GitHub:
   - https://github.com/kronbii
2. Include:
   - A clear description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested mitigation (if available)

## Response Expectations

- Initial acknowledgment: within 7 days
- Triage and remediation plan: as soon as practical based on severity
- Public disclosure: after a fix is available or coordinated timeline is agreed
